# 本地二开变更记录

记录每一次**有意偏离上游**的改动。用途：

1. 同步上游时，这份清单 = 需要重点回归测试的范围；
2. 解冲突时，这里写着"为什么改"，避免把上游的修复连同你的改动一起丢掉；
3. 上游后来实现了同样功能时，这里是你**敢删掉自己那份代码**的依据。

**规则**：每次 `local:` commit 都必须在这里加一行。改了哪、为什么、上游对应功能是什么。
